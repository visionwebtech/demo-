# Croft House, Jaipur — Website (complete package)

This ZIP contains the FULL Croft House website in two forms:

1. `site/`   — A ready-to-open static build. Double-click `site/index.html`
              and the website runs in any modern browser. No build step
              or internet connection is required to view.

2. `source/` — The editable Vite project. Run:
              ```
              cd source
              npm install
              npm run dev        # http://localhost:5173
              ```
              `npm run build`  produces a fresh production bundle in `source/dist/`.

## Verified business data only

Every value in the code is sourced from Google Maps (place_id
`ChIJo41cbAC1bTkRnEwq2tPhq14`). No menu items, prices, hours, owner name,
email, or social handles were invented — those slots are intentionally
left empty and are easy to fill in inside `source/src/data/site.js`.
